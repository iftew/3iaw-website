// 05 — Roblox Account

Connect Roblox

Uploads use your own Roblox Open Cloud API key, so the audio goes straight to your account or group.

Roblox accountNot connected
  1. Open create.roblox.com → Credentials and create an API key.
  2. Add the Assets API with Read and Write.
  3. Under Accepted IP Addresses, add 0.0.0.0/0. Uploads are sent from 3iaw.com's server, not your PC, so this is required.
  4. Save, then copy the key and paste it below.

The key is kept in this browser and sent to Roblox (through 3iaw.com) only when you upload or check a status. 3iaw.com never stores it.

// 04 — Tutorial

How to use the converter

From an audio file to a sound playing in your Roblox game.

Video coming soon
Step by step
  1. Log in with DiscordYour account gets 2 free uploads. A plan gives unlimited uploads.
  2. Connect RobloxCreate an Open Cloud API key with Assets read and write, and paste it in Roblox account.
  3. Choose your audioUse audio you made or have permission to use, or a track from Roblox's own audio library.
  4. Pick a presetDefault keeps the sound as it is. Adjust Speed, Amplify and Max Duration if you need to.
  5. Convert & uploadThe audio goes to your account and Roblox reviews it. Follow the status in History.
  6. Use it in your gameWhen it's approved, copy the link or ID and set it as a Sound's SoundId in Roblox Studio.
