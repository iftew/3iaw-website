// 03 — Roblox account

Connect Roblox

Uploads use your own Roblox Open Cloud API key, so the audio goes straight to your account or group.

Roblox accountNot connected
  1. Open create.roblox.com → Credentials and create an API key.
  2. Add the Assets API with Read and Write.
  3. Under Accepted IP Addresses, add 0.0.0.0/0. Uploads are sent from 3iaw.com's server, not your PC, so this is required.
  4. Save, then copy the key and paste it below.

The key is kept in this browser and sent to Roblox (through 3iaw.com) only when you upload or check a status. 3iaw.com never stores it.
